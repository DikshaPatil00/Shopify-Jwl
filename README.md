Symptom Analyzer

About the Project
This project is a simple web application I built using Flask to help users understand their symptoms and get basic guidance.

The idea came from a common problem — when people feel unwell, they don’t always know what to do first. This system allows users to enter their symptoms and get:
  Home remedies
  Suggested medicines
  Emergency alerts if the condition seems serious

It’s not meant to replace a doctor, but to provide quick basic help.

What it does
  Takes user symptoms as input
  Matches them with stored data
  Shows possible remedies and medicines
  Detects severe cases and shows an emergency alert
  Stores user data and symptom history


Tech Used
- Python (Flask)
- HTML, CSS
- Basic database (for storing users and records)


How to run
1. Install requirements  
   pip install -r requirements.txt

2. Run the app  
   python app.py

3. Open browser  
   http://localhost:5000
